# Setup

Written by the main session at promotion, never by a research task. The summary describes only
`supported` and `corroborated` claims. Everything else stays in the table.

## Summary

*Isle Wars Pro*, unregistered, as read from its code: the setup offers one options screen of six controls — four seat toggles locked by the registration check to a single human, a locked five-value starting-armies choice, an unlocked three-entry strength dial, a locked four-entry event-frequency choice, an unlocked three-entry speed dial and a per-session sound toggle (C-SET-01, C-SET-04). The unregistered release restricts the seat toggles (no several-human play, no all-computer), the starting-armies choice (the human's dealt minimum) and the event-frequency choice (Normal only); strength, speed and sound are unrestricted at the gate, and the registration check itself is inert at startup (C-SET-02). The whole corpus holds exactly three files: a one-line defaults file the game creates with the same values its unregistered forcing pins, a character-shift-ciphered six-slot win/loss record that the unregistered build stops updating once its fifty-score cap is passed, and a registration file whose check re-derives a scramble of the entered name; no handler anywhere saves, loads, exports or imports a game (C-SET-05, C-SET-06). No file carries a version or format number; the reader handlers parse whatever occupies the path without validation, so missing-item conversion and foreign-contents outcomes are `unknown` (C-SET-07). Every random value in the game comes from one Director stream that nothing in the Lingo seeds — a whole-corpus search found no seed call, no seed field and no second random source (C-RND-01, C-RND-03); restored-position replay is unestablished in this build (C-RND-02).
