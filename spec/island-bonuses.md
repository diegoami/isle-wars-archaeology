# Island bonuses

Written by the main session at promotion, never by a research task. The summary describes only
`supported` and `corroborated` claims. Everything else stays in the table.

## Summary

*Isle Wars Pro*, unregistered, as read from its code: an island pays its bonus only when every one of its countries is held; partial control earns nothing, and several complete islands add up with no diminishing (C-BON-01). The nine islands partition the 46 countries into consecutive ranges and pay fixed, hand-written values — 2, 4, 4, 8, 2, 5, 2, 5, 3, totalling 35 — that track island size at about three quarters of the member count, except island 9, whose 3 countries pay 3; no formula computes them at runtime (C-BON-02). The code holds exactly one board: no group is a single country, every island carries a bonus, and countries have 2 to 5 neighbours (C-BON-03). Whether starting positions come out unequal in neighbours is a property of the random deal (T18, T28), not of the bonus code.
