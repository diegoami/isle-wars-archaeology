# setup/iw-dos/

The `iw-dos-runtime` bootstrap profile (W3b draft): `iw-dos-runtime.sh` checks the tools, makes the
run copy `<IW_DOS_RUN>/game` the registered set (`rundir.py sync`), checks it (`rundir.py check`,
which runs `register_artifact.py check --strict`), and ends with the lane's token checks
(`tokens.py`, which runs `token_check.py` and the shared tokens of `capabilities.json`). No game
files. The DOSBox-X configuration is generated by each run (`runtime/iw-dos/spike/dosconf.py`).
