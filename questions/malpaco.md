# Research questions from malpaco's rules

Every rule and constant in malpaco's `RULES.md` and `SCENARIOS.md`, turned into a question about *Isle Wars* (DOS) and *Isle Wars Pro* (Win9x). **These are questions, not claims.** Every row is `unknown`: no row says how an original behaves, and nothing here changes [knowledge-map.md](../knowledge-map.md). malpaco is read at commit `2da373d` (private); every citation is `file:line` at that commit, and each quotation is no more than part of one line. Its own warning stands: its numbers were invented, so none is a lead on the originals' values.

How to read a row:

- **Scope.** DOS, Pro or both, with the reason. `both` means the question is asked of each game on its own and answered per game (CLAUDE.md rule 19); it never means the answer carries from one game to the other.
- **Method.** `observe` runs the original and records what it does; `parse` reads the structure of a file the original writes or ships, on the user's machine; `static` analyses the binary without running it. Only structure and counts leave the user's machine, never original bytes (rule 18).
- **Priority.** **P1** bears on the stalemate (RULES.md, "Games that do not end"), on whether attacking pays, or on the AI, which malpaco never built. **P2** is any other rule. **P3** is cosmetic or depends on another answer.
- **Driver.** Any measurement over several games names who or what drove each seat (human, AI, scripted policy); POSTMORTEM.md:156 "the harness numbers must always say which driver produced them".
