# Questions

Research questions for the originals, each falsifiable and each saying which observation would answer it: [malpaco.md](malpaco.md) turns every rule and constant in malpaco's `RULES.md` and `SCENARIOS.md` (read at commit `2da373d`) into a question about *Isle Wars* (DOS) and *Isle Wars Pro* (Win9x), adds the user-interface questions that the weaknesses recorded in malpaco's own documents raise about Pro, and ends with a table showing which questions cover each heading of the two files. A question carries an id (`Q-<AREA>-<nn>`), malpaco's statement as a one-line citation, a knowledge-map area, the scope (DOS, Pro or both, with the reason), the likely method (`observe`, `parse` or `static`) and a priority (P1 for the stalemate, whether attacking pays and the AI; P2 for other rules; P3 for cosmetic ones or those that depend on another answer). A question is not a claim: every row stays `unknown` until a reviewed finding answers it, malpaco's numbers are never an answer, and this directory holds no answers and changes no knowledge-map status.
