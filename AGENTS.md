# AGENTS.md

The standing rules for any coding agent that touches this repository — Claude Code,
OpenCode, Cursor, Aider, or any other AI tool — live in
[`CLAUDE.md`](./CLAUDE.md). Read `CLAUDE.md` first; it carries the project's
process, the model-choice rules, the harness, the worktree and PR conventions, the
protected-rule list (rule 18 originals, Pro-only scope, run-record immutability),
and the rule 6 "who implements, who reviews" flow with its block list and family
rule. Follow it.

`AGENTS.md` exists so tooling that looks for an `AGENTS.md` file finds a pointer to
the project's rules without needing to know the Claude-Code name; both names refer
to the same standing ruleset.

Do not duplicate the rules in this file. When `CLAUDE.md` changes, edit
`CLAUDE.md`; this file stays one paragraph.
