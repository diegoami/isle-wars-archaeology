# AGENTS.md

The standing rules for every coding agent that touches this repository — Claude
Code, OpenCode, Cursor, Aider, or any other AI tool — live in
[`CLAUDE.md`](./CLAUDE.md). Read `CLAUDE.md` first and follow it.

This file exists so tooling that looks for `AGENTS.md` finds a pointer to the
project's rules without duplication; when `CLAUDE.md` changes, edit `CLAUDE.md`
and `AGENTS.md` stays a pointer.
