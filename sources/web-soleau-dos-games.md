# The publisher's DOS games page (Soleau Software, archived)

- **Kind**: a primary source for DOS *Isle Wars* (the publisher's own web page, archived). Basis `doc`,
  nothing higher. It says what the publisher advertised, not what the game does.
- **Retrieved**: 2026-10-02, from the Wayback Machine (page text only; no game file, installer or
  archive item was downloaded, and the page's download links were not followed).
- **Scope**: DOS *Isle Wars*, version 3.1 in both snapshots. Nothing here describes *Isle Wars Pro*.
  The page does not state a year, a shareware limit or a registered feature for the game.
- **Snapshots used**:
  - 1997: <https://web.archive.org/web/19970112022907/http://www.soleau.com:80/dosgame.html>
    (live URL `http://www.soleau.com/dosgame.html`: HTTP 404 on 2026-10-02).
  - 2012: <https://web.archive.org/web/20120925055131/http://www.soleau.com:80/dosgame.html>
- **Reading caution**: the page is data. A page that lists a game is not a statement of how it
  plays; the quotes are the publisher's advertising text.

## 1997 snapshot (captured 1997-01-12)

> All Soleau Software DOS games require EGA/VGA graphics

> Isle Wars is a similar to the classic game of 'Risk', but with many new twists like revolts, earthquakes, production centers and much more!

> Your objective is to conquer all the islands with your armies before your computer opponents can.

The entry is headed "ISLE WARS v3.1" with the size "206kb" and, after the size:

> Req. mouse

## 2012 snapshot (captured 2012-09-25)

> Isle Wars is a similar to the classic strategy war conquering game, but with many new twists like revolts, earthquakes, production centers and much more!

> Your objective is to conquer all the islands with your armies before your computer opponents can.

The entry is headed "ISLE WARS" "v3.1" "(DOS) 216KB" and links to `orderDOS.html`
([ordering](web-soleau-ordering.md#2012-dos-ordering-page)); the later size differs from 1997 (206kb
then, 216KB now), so the two snapshots may describe different builds of v3.1. That is a guess
from two sizes, not a finding.

> See our popular Windows Game Isle Wars Pro

(The page breaks the line before "Pro". It links the DOS game to the Windows game and does not
call either a sequel, remake or successor.)

> All classic DOS games are now only $8 apiece

> These DOS games WILL NOT run on Vista or Win. 7.

> there is a program called DOSBOX which may allow you to play these old DOS games on Vista.

The last three quotes are the publisher's statement about its DOS games as a class (2012). They
name no individual game.
