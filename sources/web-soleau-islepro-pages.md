# The publisher's Isle Wars Pro pages (Soleau Software, archived)

- **Kind**: a primary source for *Isle Wars Pro* (the publisher's own web pages, archived). Basis
  `doc`, nothing higher: advertising text, not a description of what the game does.
- **Retrieved**: 2026-10-02, from the Wayback Machine (page text only; the pages' download links
  were not followed and no file was downloaded).
- **Scope**: *Isle Wars Pro* only. The pages do not mention DOS *Isle Wars*.
- **Snapshots used** (live URLs `http://www.soleau.com/games/islepro.html` and
  `http://www.soleau.com/wingame.html`: HTTP 404 on 2026-10-02):
  - game page, 2002: <https://web.archive.org/web/20020608014917/http://www.soleau.com:80/games/islepro.html>
  - Windows games list, 2002: <https://web.archive.org/web/20020802155655/http://www.soleau.com:80/wingame.html>
  - game page, 2013: <https://web.archive.org/web/20130213034757/http://www.soleau.com/games/islepro.html>
- **Dates the archive gives** (capture dates, not release dates): the earliest capture of
  `games/islepro.html` is 2002-06-08. The Windows games list captured 2001-08-13 does not list the
  game; the one captured 2002-08-02 does. These bound when the publisher showed the game; they do
  not say when it was written.
- **Version caution**: the 2002 list says "v1.0"; the 2013 page says "v2.0"; the install the user
  holds is version 2.0 (`Islepro.txt`, see [iwp-islepro-txt.md](iwp-islepro-txt.md)). A claim about
  v1.0 is not a claim about v2.0.

## Game page, 2002 (captured 2002-06-08)

> for Windows & Machintosh (Req: 32 Megs Ram 800x600)

> ISLE WARS PRO is a strategy arcade conquest game in which you try to control all the islands on the game board.

> Isle Wars is a game where the outcome is affected by events such as floods, rebellions, earthquakes and much more.

> Play against the computer or your family and friends in this highly addictive game.

operating system for Pro alone):
