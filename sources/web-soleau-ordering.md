# The publisher's ordering pages (Soleau Software, archived)

- **Kind**: a primary source for how the publisher sold and unlocked its games (the publisher's own
  web pages, archived). Basis `doc`, nothing higher. It bears on registration and on the "still
  sold" row; it does not describe how any game plays.
- **Retrieved**: 2026-10-02, from the Wayback Machine (page text only; nothing was bought,
  submitted or downloaded, and the store links were not followed).
- **Scope**: the publisher's Windows games and its DOS games as two classes. These pages name no
  individual game, so they say nothing about *Isle Wars Pro* or DOS *Isle Wars* by name; what ties a
  game to a page is that the game's own page links to it
  ([DOS](web-soleau-dos-games.md#2012-snapshot-captured-2012-09-25),
  [Pro](web-soleau-islepro-pages.md#game-page-2013-captured-2013-02-13)).
- **Snapshots used** (live URLs under `http://www.soleau.com/`, all HTTP 404 on 2026-10-02):
  - 1997, `order.html`: <https://web.archive.org/web/19971022091427/http://www.soleau.com:80/order.html>
  - 2012, `order2.html`: <https://web.archive.org/web/20120818004019/http://www.soleau.com:80/order2.html>
  - 2012, `orderDOS.html`: <https://web.archive.org/web/20120927123528/http://www.soleau.com:80/orderDOS.html>
  - 2020, `order.html` (the address `Isleord.url` points to, see
    [iwp-shortcuts.md](iwp-shortcuts.md)): <https://web.archive.org/web/20200217123748/http://www.soleau.com:80/order.html>
- **Third-party seller**: the 2012 and 2020 pages send buyers to a Share*it (Digital River) store.
  The store address, `http://www.shareit.com/product.html?cart=1&productid=300524673`, answered
  HTTP 502 on 2026-10-02 (one probe at about 21:28 UTC); one failed probe is not a finding about the
  service.

## 1997 online ordering page (captured 1997-10-22)

> This service will allow you to purchase and register your Shareware product online.

> receive an unlock code via e-mail in about 3 minutes

> You must first have a copy of the program(s) downloaded from our site in order for the registration codes to work.

Prices on that page, under the headings "Windows & Macintosh Games" and "DOS Games":

> 1 Game : $18 |

> 1 Game : $12 |

(The first is under the Windows and Macintosh heading, the second under the DOS heading. The page
does not say which game costs what; the price list is by count of games.)

## 2012 Windows ordering page

Captured 2012-08-18.

> Before ordering any game, make sure that you have the Shareware game already installed on your computer and that it runs properly.

> you will be sent the unlocking codes only. You do not download anything from the store.

## 2012 DOS ordering page

Captured 2012-09-27.

> These are 8 bit DOS games which will not run on some versions of XP.

> you will be sent the unlocking codes only. You do not download anything from the store.

> DO NOT order these games unless you have them already running on your computer.

## 2020 ordering page (the shortcut's target)

Captured 2020-02-17. Its text is the same as the 2012 Windows page, plus a link headed
"To Order Our Older DOS Games".

> Soleau Software Windows Games Ordering Page

> Before ordering any game, make sure that you have the Shareware game already installed on your computer and that it runs properly.
