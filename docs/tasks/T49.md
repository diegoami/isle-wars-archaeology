# T49 Constraint F accepts run/1 objects only where records live

- **Kind**: correction (narrows T48's widened constraint-F gate, #149)
- **Issue**: #154 · **Branch**: `task/T49-run1-allowlist` · **Merge after**: T48 (merged)
- **Implementer**: opencode `mimo-flash` (MiMo v2.6 Flash on Go, no variant), after the quota check
  (rule 6). **Hard**: it changes a guard, so a mistake lets a Wine record of an unverified binary
  pass CI. Claude fallback: sonnet.

- **Why** (the owner's decision, 2026-10-09). T48's gate looks for `run/1` objects in any tracked
  JSON, at any depth, under any name, and checks the Wine ones. Five review rounds found ever-rarer
  JSON shapes that slipped past or crashed it. At T48's merge, three remain open (Sol's micro-round
  review on PR #151):
  - R1: an explicit `null` skips the shape checks (`runtime: null` or `platform: null`, with `wine`
    in another field);
  - R2: the printable-ASCII check runs on the serialised field, so `"wi\u0000ne"` hides behind its
    escape;
  - R3: a lone surrogate in a diagnostic makes `print` raise `UnicodeEncodeError` (fails closed).

  None of them is a record that claims a Wine platform. They exist because the gate interprets
  malformed JSON wherever it finds it. T49 removes that surface: records may live in one place, and
  CI already validates that place.
- **Evidence**:
  - `tests/test_runs.py` (`RunRecordsTest.test_every_committed_run_record_is_valid`) already
    validates every `runs/**/*.json` against `formats/run-1.schema.json` in CI, so odd shapes
    there already fail CI.
  - `formats/examples/` (valid and invalid) holds 15 pinned `run/1` documents (`archaeology.json`),
    some malformed on purpose.
  - T48's gate: `tools/check_no_originals.py` at `a4eeafd`.
- **Owns**: `tools/check_no_originals.py`, `tools/tests/test_check_no_originals.py`. Not `runs/**`,
  `evidence/**`, `findings/**`, `formats/**`, or `tests/test_runs.py`.
- **Scope**:
  - **The allowlist.** A JSON object with `schema == "run/1"` is allowed in two places only:
    - **the top level** of a file under `runs/` whose name ends in lowercase `.json`. These are the
      files `tests/test_runs.py` validates;
    - **the top level** of a file under `formats/examples/`.

    Any other `run/1` object is refused, Wine or not, with its path and where it sits:
    - nested at any depth, including inside an allowed file;
    - in a file under `runs/` with another name (`.JSON`, `.txt`, none);
    - in any other tracked file.

    T48's content discovery (by content, every encoding, duplicate keys refused, the depth bound)
    stays, but only to find such objects and refuse them.
  - **The gate on allowed records** is T48's, unchanged: the carve-out token against F019's row; a
    legacy Wine platform by exact path and file sha256 in `tools/legacy_wine_records.txt`;
    non-ASCII platforms refused; symlinks under `runs/` refused. It must not crash on any shape. An
    odd shape at an allowed place is `tests/test_runs.py`'s to refuse. The gate either refuses it
    (when it names `wine`) or leaves it, but never raises.
  - **Diagnostics** escape every value taken from a document (`ascii()`, or `repr()` and an ASCII
    encode), so no input can make the check crash while printing.
  - Once the allowlist makes them unreachable, T48's odd-shape helpers may be simplified. Keep what
    allowed records still need.

- **Hazards**:
  - **An allowlist matched loosely.** Check the path as git lists it. `runs/` is a prefix of the
    path's first component, compared exactly. The `.json` test is case-sensitive, which is what
    `tests/test_runs.py`'s `rglob("*.json")` sees. `formats/examples/` is compared exactly too. A
    path like `runs.json`, `runsx/a.json`, `formats/examples-x/a.json` or `docs/runs/a.json` is
    not allowed.
  - **Top level means the document's root object**, not the first object found in a walk. A
    `runs/` file whose root is an array holding a record is refused.
  - **Weakening the T48 gate** for allowed records while simplifying. Every pinned test still passes.
  - **A crash.** The check never raises on input. Diagnostics are escaped.
  - **The memory cap.** Every test command runs under it.
