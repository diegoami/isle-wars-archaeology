# T55 The single-exchange sitting: 20+ computer-vs-computer exchanges from a model sitting

- **Kind**: model-driven (runs the original under rule 18's carve-out, process.md §10; its preconditions
  are Done-when lines). The offline reader and checker are T44; this task runs the sitting that uses them.
- **Issue**: #222 · **Branch**: `task/T55-single-sitting` · **Merge after**: T44 (#142).
- **Implementer**: the main session directly (the sitting reads the user's install, L26).
- **Reviewer**: opencode `gpt-6.1-sol` (GPT-6.1 Sol, effort `low`), another family; substitute `luna`.
- **Why**: the E020 sittings gave 0 single exchanges (T44's Why). T44 gives the reader a single exchange
  (one die changes exactly one counter, `event:seq`, never `net:seq`) and the checker
  `tools/check_counts.py --accept-single`; a real sitting is what turns those into T28's corroboration counts.
- **Evidence**:
  - **T44** (the reader mechanism and the `--accept-single` checker) and its static reading (candidate 2: a
    faster capture, T42's watcher at 8 fps; candidate 1, the `speed` option, dropped).
  - **The E020 sitting pipeline**: `experiments/E020-wine-first-run/e020_loop.py`, `e020_sitting.py`,
    `e020_export.py`, `launcher.py`; `walkthroughs/video-walkthrough.md` and `walkthroughs/coordinates.md`.
  - **F019** (the known-good `Islepro.exe` sha256 the record's `start_state.sha256` must match).
- **Owns**: `runs/E022/sitting/**`, `evidence/E022/**`, and the E022 sitting invocation under
  `experiments/E022-pro-fast-capture/**`. Read-only: the install and run copy, `experiments/E020-wine-first-run/**`.
- **Scope**: run one model sitting under `wine-on-user-machine-iwp-2.0` for `iwp-2.0-996e86c5` (the
  unregistered set) on the main session's own Xvfb (Wine 10.0, xfwm4, xdotool), with the T42 watcher at its
  fast schedule and, if T44's static reading finds it helps, the game's `speed = slow` option read through the
  driver's options cycle (never a patch, rule 18). Export the sitting's frames with the T44 reader into a
  `run/1` record. **Not in scope:** any per-claim outcome in a finding (that is T28's F021), and running T45's
  Session A on top of this mechanism.
- **Done when**:
  1. `runs/E022/sitting/E022-r<NNN>.json` holds at least 20 single exchanges accepted by
     `python3 tools/check_counts.py --accept-single experiments/E022-pro-fast-capture/scenarios.txt` (not
     `net:seq`), under a committed path; a test fails when the single-exchange test is removed (T44's).
  2. `python3 tools/check_no_originals.py` passes: constraint F accepts the record iff its
     `start_state.sha256` is the F019 row's hash for the set+variant it names.
  3. `python3 tools/check_links.py` passes, and CI is green.
- **Hazards**:
  - **Carve-out A (locality).** The binary, install, run copy, savestates, frames and dumps stay on the
    user's machine, never in the repo, an issue or a cloud session; per-frame evidence is class `recording`.
  - **Install seal (rule 18 B; #204).** Reads only; the install is bound read-only for every run; the run copy
    is the only write.
  - **Original text** (constraint D): the record names labels by role, never quotes them.
  - **The deal is random** (F018): the sitting records whatever the runner saw.
**Runs on**: `artifact:iwp-2.0-996e86c5` (the unregistered build, through the same wine prefix as T45) ·
cloud: C3 only (the install is on the user's machine) · network: N1 for push · GitHub: `gh:push gh:pr`.
Driver commit pinned in the record's `runtime.driver`; `start_state.sha256` is the F019 row's.
