- **Owns**: `artifacts/known.json` (the new set only), `artifacts/iw-dos/**`, `findings/F004-*`.
- **Scope**:
  - **The set**: every file of the archive as acquired, the 1997 files included, so that the id is
    reproducible from the same zip. The notes name the 1997 files, and say why they may not be the
    publisher's.
  - **Label and version**: `iw-dos-<version>` from what the artifact states. Cite the file and
    line, for example `ISLEWAR.DOC` or `FILE_ID.DIZ`. If it states none, use the archive's name
    and the publisher's "v3.1", and say so.
  - **`acquired`**: how, when, and the URL. In `notes`: the archive's sha256 and size; that it is
    the shareware (unregistered) release; and that dosgames.com is a third-party archive, so the copy
    may differ from the publisher's own distribution.
  - **`runtime_writes`**: `[]`, because nothing has been observed; W3b measures it.
  - **`artifacts/iw-dos/<set-id>.md`**: each file's role (program, overlay, data, document,
    distributor addition), the re-hash one-liner from Hazards, and what the archive dates show.
  - **F004** (proposed): the identity facts, each with its source:
    - the stated version;
    - `ISLEWAR.EXE`'s MZ header fields (offsets cited), and any compiler or overlay-manager
      signature found by reading strings (static, I1). Name the tool, but do not decompile;
    - the overlay files, and what references them, if a string shows it;
    - the archive's file dates, as dates of the files, not a release date;
    - any registration or unregistered-version limit that a document states.

    Basis `doc` and `static:bytes`; Artifact: the new set; Experiment: none. It does not settle
    the release year: it says what the dates do and do not show.
  - **Not in scope**:
    - running the game (W3b);
    - quoting the documents into the knowledge map (a later DOS documentation task);
    - decompiling anything.

- **Hazards**:
  - **Writing to the copy, or copying any of its files into the worktree, even temporarily.** Hash
    it in place.
  - **A machine path, the user name, or the download location** in a committed file. The URL is
    public and allowed; the local directory is not.
  - **Reading a date as a release date.** The archive's 1994 dates are file dates.
  - **The PowerShell one-liner:**
    `$r=(Resolve-Path $dir).Path; gci -LiteralPath $r -Recurse -File | % { '{0}  {1}  {2}' -f (Get-FileHash -LiteralPath $_.FullName -Algorithm SHA256).Hash.ToLower(), $_.Length, $_.FullName.Substring($r.Length+1).Replace('\','/') }`
