- **Owns**: `artifacts/known.json`, `artifacts/iwp/**`, `findings/F001-*`.
- **Scope**:
  - **The set**: every file in the install except the Inno uninstaller pair. `unins000.dat` records
    the install itself, so it would make the id depend on the machine. Exclude both with `--exclude`
    and name them in `notes`.
  - **Label and version**: `iwp-<version>` from what the artifact states. Cite the
    `Islepro.txt` line. The projector's PE version resource describes Director, not the game; record
    it separately and never use it as the game's version.
  - **`acquired`**: `user-supplied install`, the install date, and in `note` where the installer came
    from, as the user states it (the main session supplies this in the brief). If the user still has
    the installer, its sha256 goes in `notes`.
  - **`runtime_writes`**: `[]`, because nothing has been observed yet. W3a measures it, and if the
    runtime changes a listed file, W3a registers a successor set (05 §2).
  - **`artifacts/iwp/<set-id>.md`**: the role of each file (game, Xtra, document, installer
    shortcut) and the PowerShell one-liner from Hazards.
  - **F001** (proposed): the identity facts, each with its source:
    - the stated version;
    - the PE header's machine type and link timestamp, and its version-resource strings;
    - the Xtras' names.

    Basis `doc` and `static:bytes`; Artifact: the new set; Experiment: none.
  - **Not in scope**: launching the game (W3a), or limits that only play shows. Documented limits
    go to W2a.

  2. `[C3]` `python3 tools/register_artifact.py check "$IWP_DIR" <id>` exits 0. Its only `unlisted:`
     lines are `unins000.dat` and `unins000.exe`.
  3. `git grep -n -i -E 'program files|/mnt/|[a-z]:\\\\|solsoft/' -- artifacts findings` prints nothing.
  4. `[C4]` The user runs the PowerShell one-liner on Windows and posts its output on the PR (hashes,
     sizes and relative paths only). `check --list <that output> <id>` then exits 0. This is the

  5. F001 follows `formats/templates/finding.md`. Its status is `proposed`, and every fact cites a
     file and line, or an offset.
  6. `python3 tools/check_no_originals.py` and `python3 tools/check_links.py` exit 0, and CI is green.
- **Hazards**:
  - Never copy, move or open for writing anything in the install. Hash it in place. Nothing from it
    enters the worktree, not even temporarily.
  - No machine path, user name or install path in any committed file.
  - The one-liner:
    `$r=(Resolve-Path $dir).Path; gci -LiteralPath $r -Recurse -File | % { '{0}  {1}  {2}' -f (Get-FileHash -LiteralPath $_.FullName -Algorithm SHA256).Hash.ToLower(), $_.Length, $_.FullName.Substring($r.Length+1).Replace('\','/') }`
