# T02 Registration tools and the guards that use them (W1a prerequisite)

- **Kind**: infrastructure (folds bug #3)
- **Issue**: #<n> (filed on approval) · **Branch**: `task/T02-register-tools` · **Merge after**: T01
- **Implementer**: opencode `deepseek-flash` (DeepSeek V4.1 Flash, high), the measured default
- **Reviewer**: opencode `luna` (GPT-6 Luna, direct OpenAI, high), the measured default
- **Why**: W1a registers *Isle Wars Pro* by hash (05 §3: `tools/register_artifact.py`, "copied,
  ~50 lines"). The toy repo's copy (Y1) does not exist yet, so this repo writes its own. W1a and W2
  work beside original files that the extension guard misses: `.x32` (Director Xtras, which are
  DLLs), `.txt`, `.dat`.
- **Evidence** (game-archaeologist at the commit `archaeology.json` pins):
  - `formats/README.md`, "Two rules no schema can express", rule 1: the id is `<label>-<h8>`, where
    `<h8>` is the first 8 hex of the sha256 of the canonical manifest. The canonical manifest drops
    `id` and `acquired`, sorts `files` by `path`, and serialises with sorted keys, separators
    `(",", ":")`, UTF-8 and no ASCII escaping.
  - `formats/artifact-set-1.schema.json`; `formats/examples/{valid,invalid}/artifact-set-1--*.json`
    (the valid toy example's id is `toy-1.0-1ff31629`).
  - `tests/formats/check_examples.py`: `validate`, `semantic_errors`, `canonical_set_hash`. Its
    `main()` is guarded, and its root is two directories up, so a copy at the same path reads the
    vendored `formats/`. game-archaeologist#10 will replace copies with a pinned fetch.
  - Bug #3: `.gitignore` misses mixed-case extensions (`probe.Exe`, `probe.PNG`).
- **Owns**: `tools/register_artifact.py`, `tools/check_no_originals.py`, `formats/**` and
  `tests/formats/check_examples.py` (vendored), `tests/**`, `archaeology.json`, `.gitignore`,
  `.github/workflows/ci.yml`, `artifacts/README.md`, `README.md`.
- **Scope**:
  - **Vendor**, whole and unchanged, `formats/artifact-set-1.schema.json`, the artifact-set examples
    and `tests/formats/check_examples.py`. Record their source commit and each file's sha256 in
    `archaeology.json`. `register_artifact.py` imports `validate`, `semantic_errors` and
    `canonical_set_hash` from the vendored file, and never re-implements the canonical id.
  - **`register_artifact.py`**, stdlib only:
    - `manifest <dir> --label --title --version --how --when [--note] [--runtime-write G]… [--exclude G]…`
      prints an artifact-set/1 entry. Files matching `runtime_writes` or `--exclude` are left out of
      `files`, and `--exclude` is not recorded.
    - `check (<dir> | --list <file>) <set-id>` re-hashes against the `known.json` entry. A `--list`
      line is `<sha256>  <bytes>  <relative/path>`. It exits 1 on any mismatch or missing file. An
      unlisted file is printed as `unlisted: <path>` (an exit-1 failure only with `--strict`).
    - `validate` checks every `known.json` entry against the schema and recomputes its id.
  - **`check_no_originals.py`**: also fails on a tracked file whose sha256 equals any file hash in
    `artifacts/known.json`, and on `.x32`.
  - **`.gitignore`**: case-insensitive patterns (`*.[eE][xX][eE]`), plus `.x32`.
  - **CI** runs `python3 -m unittest discover -s tests`.
  - **Not in scope**: `machine.json` and preflight (H3), any real artifact, and `check_quotes.py`
    (T06).
- **Done when**:
  1. `python3 -m unittest discover -s tests -q` passes. Every test below fails when its behaviour is
     removed; the PR says how that was checked.
     - The vendored toy example recomputes to `toy-1.0-1ff31629`, and both invalid artifact-set
       examples fail `validate`.
     - A temp dir: `manifest`, then `check` passes. One flipped byte makes it exit 1. A `--list` of
       the same files gives the same id. A file matching `runtime_writes` is excluded and ignored.
     - An unlisted file prints `unlisted:` and exits 0, or 1 with `--strict`.
     - In a temp git repo, staging a file whose bytes match a `known.json` hash makes
       `check_no_originals.py` exit 1, and so does staging `a.x32`.
  2. `touch probe.Exe probe.PNG probe.x32 && git check-ignore -q probe.Exe probe.PNG probe.x32; echo $?; rm probe.*`
     prints `0`.
  3. Each vendored file's sha256 equals that of the file at the pinned commit, fetched with
     `gh api repos/diegoami/game-archaeologist/contents/<path>?ref=<sha>` and the
     `Accept: application/vnd.github.raw` header.
  4. `python3 tools/check_no_originals.py`, `python3 tools/check_links.py` and
     `python3 tools/register_artifact.py validate` exit 0, and CI is green.
- **Hazards**:
  - editing a vendored file (line 3 fails), or re-implementing what it already provides;
  - writing a fetched file outside the worktree (L26 fails the run): pipe `gh api` into
    `sha256sum`;
  - tests that only exercise the happy path;
  - no fixture is ever a real game file; synthetic bytes only.
