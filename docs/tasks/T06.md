# T06 The quote checker (W2a prerequisite)

- **Kind**: infrastructure
- **Issue**: #8 · **Branch**: `task/T06-check-quotes` · **Merge after**: T02 (its
  CI step runs the tests)
- **Implementer**: opencode `glm-5.3` (GLM-5.3 on Go, high), a trial under CLAUDE.md rule 21. In
  IC2 (L27) GLM-5.3 ended long implementer runs early. This task is small enough to show whether
  that recurs, and to diagnose it if it does.
- **Reviewer**: opencode `gpt-6-sol` (GPT-6 Sol, direct OpenAI, high), a trial
- **Why**: W2a (T04) quotes `Islepro.txt` and `Order.txt` into `sources/`. The user asked for them
  to be quoted, never copied whole (2026-10-02). A reviewer needs a command that proves both.
- **Evidence**:
  - The user's instruction above.
  - 07 §4, W2: "reviewer samples 5 rows and finds the quoted text".
  - Both originals are short plain-text files (about 10 KB and 3 KB, per the main session's listing
    of 2026-10-02). Their encoding is not known; Windows text of that era is usually cp1252.
- **Owns**: `tools/check_quotes.py`, `tests/test_check_quotes.py`.
- **Scope**:
  - **`check_quotes.py <original> <sources.md> [--encoding cp1252]`**, stdlib only:
    - Every `>` blockquote line in the sources file must occur in the original once whitespace is
      collapsed on both sides. A blockquote line that is only a citation (`Islepro.txt:12-14`) is
      not a quote.
    - The quoted characters must not exceed 25% of the original's characters. 25% is a designed
      policy value, not a finding; say so in the code.
    - It prints each failing quote with its line number in the sources file. It exits 0 when all
      pass, 1 on any failure, and 2 on usage errors.
  - **Not in scope**: running it on a real original. The tests use synthetic text only.
- **Done when**:
  1. `python3 -m unittest tests.test_check_quotes -q` passes, with tests that:
     - pass on a valid quote set;
     - exit 1 on a quote absent from the original;
     - exit 1 on a quote share over 25%, and pass at exactly 25%;
     - match across a line wrap that differs between the original and the quote;
     - decode a cp1252 byte (for example `0x92`) correctly.

     Each test fails when its behaviour is removed; the PR says how that was checked.
  2. `python3 tools/check_quotes.py` with no arguments exits 2.
  3. `python3 tools/check_no_originals.py` and `python3 tools/check_links.py` exit 0, and CI is green.
- **Hazards**:
  - Normalising so loosely (case, punctuation) that a paraphrase passes. Collapse whitespace only.
  - Counting citation lines as quotes, or counting a repeated quote twice against the cap.
  - Fixtures that are real game text. Synthetic only.
- **Runs on**: base, `tool:python@>=3.11`, `svc:opencode-go`, `svc:openai` · cloud: C0 · network: N2 · GitHub: `gh:push gh:pr gh:issues gh:labels`
