  cheaply, and at what intervention level. W5a's driver, the research backlog (W6) and every
  experiment after it choose their observations from this inventory.

- **Scope**:
  - **Reach the screens.** Record runs that reach, and screenshot, each of these, cheapest path
    first:
    - title, Options;
    - the New Game setup, with every control and its default (feeds Q-SET-01 and Q-PLY-03);
    - the board at the start of a game;
    - one human turn: one placement or move, and one attack with its dice result;
    - an AI turn passing, if one does;
    - Help, Scores, and the unregistered notices.

    Never click Soleau Games or any order or website button. Where a screen cannot be reached,
    record `not reached: <why>`.
  - **The sources.** For every source found, record:
    - what state it shows;
    - its class: `directly-observable` (screen regions, window title, process state), `parsed`
      (a file or registry value the game wrote, read at I0), `inferred` (state derived from a
      sequence of observations), or `invasive` (I1 and above: memory reads, a debugger, extracting
      the Director movie or its Lingo scripts, crafted saves);
    - its intervention level and its cost (seconds, and how many runs it needs);
    - the runs that show it.

    Order the table cheapest first. Candidates to test:
    - screen regions: territory colours, army numbers, the turn and phase indicators, the dice, the
      messages;
    - the game's files: `xtras/Isledft.dat`, `xtras/Islepro.dat`, `xtras/Islepro.skr`, and any
      save or score file;
    - registry keys;
    - the Temp folder;
    - the window title;
    - process memory, classified only.
  - **Parsed sources.** For each one:
    - its format as far as observed: byte offsets, fields, encodings;
    - each field's meaning, shown by at least two runs whose values change in line with a known
      action, such as Isledft.dat before and after "Save as default" with a known setting changed.

    Each becomes a proposed representation row in F003 (ID, representation, scope `Pro`, basis,
    runs).
  - **Saves** (Q-SET-05): does the game save and load a game? Where, under what name, and does a
    save change when the board changes? Record the answer, even if it is no.
  - **In-game text.** Where Help or another screen shows text that `Islepro.txt` does not have,
    add it to the knowledge map as `documented` (Pro). Use short quotes of a line at most, each
    citing its screenshot bundle and run. Never a full transcription.
  - **#27.** `snapshot_tree` refuses, or aborts on, any entry that is not a regular file, a
    directory or a link, instead of reading it. Add a test that visits the edge.
  - **Speed**, from `docs/models.md`:
    - terminate with Alt+F4 or `wineserver -k` except where the quit path itself is observed;
    - a run may visit several screens in one launch;
    - record the time each run took.
  - **F003** (proposed), from `formats/templates/finding.md`:
    - Artifact `iwp-2.0-996e86c5` (or its successor where a run writes); Experiment E002; tier
      V2; the maximum intervention as observed, I0 or I1 (screenshots);
    - the source table;
    - the proposed representation rows;
    - the screens reached;
    - "What this does not establish".
  - **Not in scope:**
    - any claim about a game rule (how combat or reinforcement works): sources only;
    - decompiling or extracting the Director movie or its Lingo scripts, which are classified
      `invasive` and not performed;
    - memory reads beyond classifying them;
    - crafted or modified saves (I3);
    - the W5a driver.

- **Hazards**:
  - **Claiming a rule from an observation.** This finding says where state can be seen, not how
    the game decides it.
  - **One run taken for a format.** A field's meaning needs two runs whose values differ in line
    with a known action.
  - **Weakening T08's seal to reach a new screen.** Every launch goes through the same checks, and
    a new screen is reached by input, never by changing the prefix.
  - **Game text beyond short quotes, or a game file, entering the repository** (rule 18).
  - **Clicking Soleau Games, an order button or a website link.**
  - **An Opus round** (escalation) starts from the pushed branch and weighs any unpushed patch;
    it never applies one blindly.
