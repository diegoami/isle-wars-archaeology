    and is not a file). For each, run `python3 tools/check_citations.py findings/<file>` to

    no second paragraph in a list item); commit the fix with a message that names the count
    (e.g. `findings/F003: 21 uncited bullets, 1 second paragraph — citations added, structure
    flattened`). The push goes to the same branch (`task/T25-check-citations`).
  - **Milestone per finding (L58):** the tool's per-file outcome is itself a result; each
    finding's pass is its own commit. A finding's Done-when is `check_citations.py` exiting 0 on
    that file. The boundary sits at a finding, not at an arbitrary half of the cleanup.
  - **A recorded decision per change (game-archaeologist U26 / U29):** if a finding's author
    already used short run ids (`r0004` for `E001-r0004`), the change to the full form is a
    mechanical rewrite. If a finding has an unsupportable bullet, the implementer does not
    remove it; they file an issue and move on. The PR carries a "decisions taken" section per
    finding.
  - **CI wiring:** the implementer adds a CI step that runs `python3 tools/check_citations.py
    findings/` over every finding. The step fails on any non-zero exit, with the per-file
    output. The wiring is the same shape as the existing `check_no_originals.py` and
    `check_links.py` steps.
  - **What this does not establish:** new rule claims; a content review of any finding
    (Sol/Luna re-running `check_citations.py` is a structural check, not a claim-content
    review). The F010+ run is a one-off report — the implementer notes any new finding that

    rules).

    needed change is upstream first, then the pin bumps.
  - **Editing a finding's claim text** for content: T25 is a structural pass. The reviewer
    refuses a commit that changes a claim's wording beyond citation form.
  - **The schema files** (`formats/*.schema.json`): the tool may not need them all; the
    implementer brings the ones the tool's `--help` names, and stops there.
  - **The "static claims" form** (`static:<path>[:line]`, per game-archaeologist#29): not
    adopted; the implementer notes that the tool's static-claim rule is permissive for now.
