  board moves without attacking, and malpaco needs these rules to decide what to keep.

- **Scope**:
  - **Protects:** rule 18 (no line of decompiled code in the repository, the PR or a comment; describe
    in our own words, cite script number, name and handler); a static reading is a reading (every claim
    says it is read from code, with a confidence, and none is stated as observed behaviour of the
    running game); rule 19 (Pro only, set `iwp-2.0-996e86c5`, unregistered).
  - **F015** (proposed), template headings as F011's to F013's, for each of the 15 questions:
    - the answer as read, in our words, with its numbers: what a production centre does when armies
      sit on it (the doubling and its timing), how many there are, where they start and how and when
      they move, whether they can be captured or destroyed; each hazard's trigger, its gate (the
      39-country event gate F012 found, the turn count, the setting), what it does and to how many
      countries, and its frequency as the code draws it; the setting's range and its default, and
      what the unregistered build locks;
    - its sources: script number and name, handler, and the binary's sha256 (`static:decompile`);
    - its confidence (rule 22), and what would change it;
    - its corroboration plan for T28 (what to count in recorded play), or `static-only` with why;
    - where the human's and the computer's paths differ, both (an event should not differ; say so
      from the code, not by assumption).
  - Tables a later task can use, in our own words: the hazard table (hazard, trigger, gate, effect,
    size) and the centre rules.
  - **"What this does not establish"**: at least the decompiler's runtime faithfulness, the undecoded
    score (frame order), the registered build, anything gated by `UPG`, and the measured frequencies
    in play (T28 counts them; the code's draw weights are not the played rates).
  - **Not in scope:** income, placement and cards (F013, T22), combat (F011), turn order, victory and
    surrender (F012), the AI's choices (T27); any run.

- **Hazards**:
  - **Quoting code** to make a point (rule 18).
  - **A rule from a name**: read the body; trace the call chain and when each value is computed; the
    earthquake code is not found by name — search for it.
  - **One path for both sides**: check whether events run identically for every seat; say it from
    the code.
  - **Stating a reading as the running game's behaviour**: T28 corroborates.
  - **Harmonizing with F012**: if the event gate or timing disagrees with F012, say so; a
    contradiction is a finding, not something to smooth over.
