- **Scope**:
  - **Protects:** T08's seal on every launch (the prefix check before anything starts and again
    immediately before the game starts; the read-only bind of the install; `safeio.py` for every
    write; `completed` only on a clean finish), and the meaning of `completed`: a cycle records it
    only when it reached its known before-state, acted, observed, and reset the prefix to its
    baseline.
  - **The driver**, a small API that a later experiment imports, never a new command per run:
    - start a session (the seal, Xvfb, xfwm4, launch);
    - wait for a named known screen, by pixels and never by a fixed wait without a stated reason;
    - perform a step (the E002 step language);
    - observe (a screenshot by hash, a region, a file the game wrote);
    - terminate and reset to the baseline.

    Every failure raises a named error, and a cycle that hits one records `aborted: <reason>`.
  - **The cycle**, built on the driver: launch → the title screen → one input (Options) → before and
    after screenshots → terminate → reset, repeated 10 times in one command. Record one `run/1`
    record per repeat, under `runs/E004/`.
  - **Recovery:** kill the game (`wineserver -k` from outside, or SIGKILL of the game process)
    mid-cycle. The driver records that repeat `aborted`, resets, and the next repeat starts from the
    baseline. A test with a fake game visits this edge, and one `[C3]` run shows it on the real game.
  - **#40's items:** cut the 30 s wait after `wineserver -k` by waiting on the run's own marked
    processes (`IWP_CYCLE_RUN`) with a bounded poll. Unset, or refuse, a stale
    `DBUS_SESSION_BUS_ADDRESS` for the run, with a clear message. Record the new time per cycle.
  - **F006** (proposed), short and like F002: the cycle's time per repeat (median and range over the
    10), the before-hash identity, the recovery result, and "What this does not establish". Artifact
    `iwp-2.0-996e86c5` (or its successor where a run writes); Experiment E004; tier V2; max
    intervention I1 (screenshots).
  - **Not in scope:** any game rule; playing a full game; the board's random start; W7a's
    determinism experiment; H3; DOS Isle Wars.

- **Hazards**:
  - **Weakening the seal for speed.** A faster cycle that skips a check is a failure, not a gain.
  - **Fixed waits without a reason.** Wait on pixels or on the run's own processes.
  - **Touching another session's processes** (#32): only processes marked with this run's
    `IWP_CYCLE_RUN`, or whose `WINEPREFIX` is this repository's prefix.
  - **Clicking Soleau Games, an order button or a website link.**
  - **A rule claimed from an observation.**
