# T44 Single computer-vs-computer exchanges: the offline reader (split from the sitting)

- **Kind**: research plus a small mechanism — a static-first Lingo reading, and the reader and checker
  that turn one die into a counted single exchange, all offline. The live sitting is T55 (rule 26 split:
  this part merges on its own without touching the user's install).
- **Issue**: #142 · **Branch**: `task/T44-single-reader` · **Merge after**: #141 (driver aborts, merged),
  the `harness_imperial` 610f979 bump (`harness.lock`), and T45 (#143, merged).
- **Implementer**: the main session directly (CLAUDE.md rule 6.1: this OpenCode session cannot spawn the
  Claude Code `implementer` subagent). **Hard** — a new mechanism across the reader and the checker.
- **Reviewer**: opencode `gpt-6.1-sol` (GPT-6.1 Sol, effort `low`), another family; substitutes
  `zai-glm-5.3`, then `luna`.
- **Why**: the E020 sittings gave 0 single exchanges and 55 net observations
  (`experiments/E020-wine-first-run/outcomes.json`), so Q-CMB-04..07 and Q-CMB-11 stay unestablished. The
  owner decided on 2026-10-09 that this needs "a faster capture (a later task)". T42 made the watcher
  fast (8 fps wanted, 5 required), so the capture already exists; the gap is the reader: one die changes
  exactly **one** counter, which `reader/exchange_events.py` reads as `one-change`, never an exchange.
  This task builds that mechanism and its offline test; T55 runs the sitting that uses it.

    **F002, F003, F018, F019**.
- **Owns**: `experiments/E022-pro-fast-capture/**` (new: the README with DW1's static reading, the

- **Scope**:
  - **Static-first gate (rule 24, 18B).** DW1's reading names the `speed` option's effect on the `count*()`
    waits and the per-die path; it drops candidate 1 (slow speed) and picks candidate 2 (a faster capture,
    already T42's watcher).
  - **The single-exchange mechanism** (`experiments/E022-pro-fast-capture/single_exchange.py`): a frame pair
    where exactly one country's counter dropped by exactly 1, its owner is unchanged, and it borders exactly
    one country of the seat in turn yields a **single** exchange — the four counters, the two countries, the
    two owners, and a `single:rank` marker — exported as an `event:seq` observation, never `net:seq`.
  - **`tools/check_counts.py --accept-single`**: with the flag, the checker accepts the `single:rank` field (a
    single die) and counts the observation as an exchange; without it, the field's kind is unknown and the
    observation is refused, so it is never counted. `--experiment`/`--records-root` keep the E020 path unchanged.
  - **Not in scope:** the live sitting (T55), running the game, any per-claim outcome in a finding (T28's
    F021), changing the E020 sitting shape.
- **Done when**:

     option's handlers and its multiplication of the `count*()` waits, the per-die path in `computerrolldice`,
     why candidate 1 is dropped and candidate 2 (T42) is picked, and the F019 row whose `Islepro.exe` sha256
     the sitting will name. No images; no decompiled Lingo in the diff.
  2. **Offline test** (`tools/tests/test_e022_single_exchange.py`) that fails on `main` and passes on the
     branch: two synthetic board readings differing by exactly one country's counter −1 (owner unchanged, the
     country bordering exactly one seat-owned country) go through the mechanism to one single exchange naming
     the attacker, defender, both counters and both owners; it is written as an `event:seq` observation in a
     synthetic `run/1` record under `runs/E022/`; `python3 tools/check_counts.py --accept-single
     experiments/E022-pro-fast-capture/scenarios.txt` counts it as one exchange and exits 0; the same check
     without `--accept-single` refuses it (not counted). A two-change pair is never a single. Synthetic pixels
     only; no original PNGs (rule 18).

  - **Original text** (carve-out constraint D): the Lingo's labels are named by role in the observation, never
    quoted in the record.
  - **The deal is random** (F018): the mechanism reads whatever the frames show; it assumes nothing about sizes.
  - **No original files** (rule 18): the offline test uses synthetic board dicts and synthetic frames only;
    `tools/check_no_originals.py` gates them.
