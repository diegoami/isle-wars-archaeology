- **Implementer**: claude sonnet (`task-agent`, high), worktree isolation, on the user's machine
  (C3, no web)
- **Reviewer**: opencode `luna` (GPT-6 Luna, high), another family (rule 6). The main session runs
  the `[C3]` line and posts its output on the PR. The review states the tier it reached.
- **Why split from W2**: 07 §4 runs W2 on C0 with public sources only. The user has made
  `Islepro.txt` a primary source, and it stays on this machine (U2). Under 04 §11, web research
  (N4) may not run on a machine holding originals. So the local documents are read here, offline,
  and the public web is read in T05.
- **Evidence**:
  - The set registered in T03. In it are `Islepro.txt` (the in-game directions, a primary source per
    the user), `Order.txt`, and the shortcuts `Islepro.url` and `Isleord.url`.
  - The user's report (2026-10-02): the game can no longer be bought, because Soleau Software no
    longer exists. This contradicts malpaco `DECISIONS.md:512-513` ("still sold"). It does not
    change U2.
  - `vocabulary/basis.md`: `doc` can make a claim `documented`, and nothing higher.
- **Owns**: `sources/iwp-*.md`, `sources/user-*.md`, `knowledge-map.md` (the Pro column, the basis
  and sources columns, and the secondary table).
- **Scope**:
  - **`sources/iwp-islepro-txt.md`** and **`sources/iwp-order-txt.md`**: the set id, the file's sha256
    from the manifest, the date read, and short `>` quotes. Each quote is cited as
    `Islepro.txt:<line>`. Quote only what a map row needs; never the whole file.
  - **`sources/iwp-shortcuts.md`**: the URLs the `.url` files point to, as data.
  - **`sources/user-2026-10-02-availability.md`**: the user's statement, as given, with its date.
  - **`knowledge-map.md`**:
    - Each area that `Islepro.txt` describes moves to `documented` in the Pro column only, with basis
      `doc` and its quote anchors. The DOS column stays as it is.
    - Anything `Order.txt` says registration unlocks becomes a new row, `documented` and scoped
      "Pro, as documented by the unregistered build".
    - Each secondary assertion stays `unknown` and gains any quote that bears on it. The "still
      sold" row also cites the user's report as contradicting it.
  - **Not in scope**: web pages (T05), and running the game.
- **Done when**:
  1. `[C3]` `python3 tools/check_quotes.py "$IWP_DIR/Islepro.txt" sources/iwp-islepro-txt.md` exits 0,
     and so does the same command for `Order.txt`.
  2. No cell is above `documented`:
     `grep -n -E '\| *(hypothesis|supported|corroborated|refuted|contested) *\|' knowledge-map.md`
     prints nothing.
  3. The DOS column is unchanged from `origin/main` (a short `python3` column diff, quoted in the PR).
  4. Every `documented` cell names a `sources/` file and anchor. The reviewer checks every row. The main
     session reads five quotes in the original and posts them on the PR.
  5. The secondary table is still all `unknown`, and the "still sold" row cites the user's report.
  6. `python3 tools/check_no_originals.py` and `python3 tools/check_links.py` exit 0, and CI is green.
- **Hazards**:
  - paraphrase that claims more than the quote says;
  - a Pro document scoped to "both";
  - a whole section quoted to "save time" (line 1 caps the share at 25%);
  - personal data from `Order.txt` beyond the publisher's business details.
