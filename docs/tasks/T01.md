# T01 The research repository: layout, knowledge map, guards (W0)

- **Kind**: infrastructure
- **Issue**: #1 · **Branch**: `task/T01-research-repo` · **Merge after**: —
- **Implementer**: claude (opus, the main session: repository structure and a map transcribed from the accepted package) · **Reviewer**: opencode (`luna`); never the implementer's family
- **Why**: W1a/W1b (artifact identity), W2 (documentation), W3x (runtime spikes) and every later
  experiment need a place to record into. The guard against committing original files has to exist
  before the first artifact task runs.
- **Evidence** (pasted from game-archaeologist, accepted):
  - `docs/phase0/02-project-architecture.md` §3, per-game repo:
    - holds `runtime/` (launch, input, observe, reset, state restore), `patches/` (with manifests),
      `parsers/`, `experiments/E<nnn>-*/`, `runs/` (run records), `evidence/` (manifests only),
      `findings/F<nnn>-*.md`, `spec/<area>.md`, `knowledge-map.md`, `artifacts/known.json` (hashes of
      known artifact sets), `capabilities.json`, `docs/tasks/`, the copied harness;
    - never holds original binaries, ROMs, data files, or anything derived from them that
      reconstitutes them, credentials or machine paths.
  - `07-delivery-plan.md` §4, W0: "private `isle-wars-archaeology` repo (U5): harness, layout with
    per-artifact dirs (`runtime/iwp/`, `runtime/iw-dos/`), `knowledge-map.md` skeleton with one
    status column per artifact (all `unknown`)".
  - `07-delivery-plan.md` §6, the knowledge-map areas: setup, players, map/topology, starting state,
    turn sequence, reinforcement/resources, movement, combat, ownership change, production centres,
    bonuses (island/continent groups, cards), hazards, AI, randomness, victory/loss, surrender.
    "Every one starts as `documented` at best (if W2 finds a primary source) and otherwise
    `unknown`."
  - malpaco's assertions (01 §6), to be tracked as **secondary, unverified**:
    - *Isle Wars* (Soleau Software, 1994, DOS) and *Isle Wars Pro*, its Win9x sequel;
    - the match rule, the failed-attack penalty, hazards, roaming production centres, the AI's
      collective surrender offer, a three-card idea, "46 countries divided between 9 continents"
      (malpaco `RULES.md:13-15`, `DECISIONS.md:208, 318-320`; `RULES.md:189-190` on the surrender
      offer).
  - Decisions U2 (originals never leave the user's machines), U3 (both artifacts), U5 (private),
    U11 (shareware releases): `CLAUDE.md` rules 18–20.
  - game-archaeologist `formats/` at `79bede9` (spec templates, `vocabulary/status.md`).
- **Owns**: everything except the harness copy in `harness.lock`, `harness.lock` and `CLAUDE.md`
  (both committed at bootstrap), and `docs/tasks/**`.
- **Scope**:
  - **The layout** above, with per-artifact `runtime/` and `setup/` (`iwp`, `iw-dos`), each directory
    holding a one-paragraph `README.md` saying what goes there (and, where it applies, what never
    does).
  - **`knowledge-map.md`**: the 16 areas, each row with a DOS and a Pro status (all `unknown`), a
    basis and a source column, plus a "Secondary assertions (malpaco, unverified)" table, every row
    `unknown` with its malpaco source.
  - **`spec/README.md`** (areas, legend, how promotion writes here) and **`spec/representation.md`**
    (an empty table), from the formats templates.
  - **`artifacts/known.json`**: `{"sets": []}`. Each future entry is `{"manifest": <artifact-set/1>,
    "notes": "…"}`.
  - **`capabilities.json`**: `{}`.
  - **`archaeology.json`**: pins game-archaeologist formats by commit.
  - **`.gitignore`** blocking original-file types and evidence media.
  - **`tools/check_no_originals.py`**: fails on a tracked file of an original-file type or larger
    than 1 MB.
  - **`tools/check_links.py`**, copied from game-archaeologist (source noted).
  - **A CI workflow**: both checks, plus the harness review self-test.
  - **`README.md`**.
  - **Not in scope**: any artifact work (W1a/W1b), documentation research (W2), runtime (W3x), and
    spec area files (written at the first promotion).
- **Done when**:
  1. `grep -E '^[0-9a-f]{64}  ' harness.lock | sha256sum -c --quiet` exits 0 (27 verbatim + 2 adapted).
  2. Every directory named in Scope exists with a `README.md`:
     `for d in runtime/iwp runtime/iw-dos setup/iwp setup/iw-dos patches parsers experiments runs evidence findings sources; do test -f $d/README.md || echo MISSING $d; done`
     prints nothing.
  3. `knowledge-map.md` has the 16 areas, each with DOS and Pro both `unknown`. The secondary table's
     rows are all `unknown` and each cites a malpaco file:line. The reviewer checks every row against
     07 §6 and 01 §6.
  4. `python3 tools/check_no_originals.py` exits 0. Committing a fake `GAME.EXE` (or a 2 MB file) in a
     scratch commit makes it exit 1. Say how this was checked.
  5. `artifacts/known.json`, `capabilities.json` and `archaeology.json` parse.
     `archaeology.json` names a game-archaeologist commit that exists (`gh api repos/diegoami/game-archaeologist/commits/<sha>`).
  6. `python3 tools/check_links.py` and `node tools/harness/review.mjs --self-test` exit 0, and CI is
     green.
- **Hazards**:
  - filling a knowledge-map cell from memory (everything is `unknown` until W2 or a finding);
  - a `.gitignore` that also hides the run records and manifests that must be committed (JSON stays
    tracked);
  - copying a game-archaeologist file without noting its source.
