# E020 batch list: exactly the batches docs/tasks/T38.md's "Why a run is made" names.
#
# The dispatcher (tools/wine-driver.sh --batch NAME --help) and tools/check_counts.py both read
# this file; the dispatcher refuses any batch that is not one of these, by name, before wine
# starts (constraint B of the rule 18 carve-out, CLAUDE.md 2026-10-08).
#
# Format: one INI block per batch.
# - `blocks` names the E002-language block file beside this one (play.steps); the launcher runs its
#   blocks in a loop (e020_loop.py) and never sends a step outside them.
# - `event` and `event_fields`: what one counted event is, and every field it carries besides
#   game:ordinal and event:seq (tools/check_counts.py: an event missing any of them is not counted).
#   Values by role: counter, hand, country, game, event, sitting are plain integers; owner is a
#   colour word (tools/check_counts.py value_problem).
# - `events_min` and `games_min`: Scope's Counts line (the first sitting's floors).
# - `games_max`, `turns_max`, `sitting_seconds`: the loop's bounds. The loop plays a game until
#   the human can no longer place (the game is over for the human) or `turns_max` turns, then starts
#   the next game, until `games_max` games or `sitting_seconds`. The events are read from the
#   frames after the sitting, so the loop cannot stop on a live count; a sitting that ends short
#   is recorded as it is, and tools/check_counts.py prints the shortfall per arm.
# - `claims`: the claim ids whose outcome tools/check_counts.py checks against their own per-arm
#   rule before `corroborated` is allowed (experiments/E020-wine-first-run/outcomes.json).
# - `vipc_countries`: Q-CMB-11's split, the fixed VIPC list as the board's country numbers (F017,
#   1 to 46): the 23 entries of the `VIPC` table in
#   experiments/E015-pro-board-reading/measurements/board-tabulation-r1e.json (T21's tabulation).
#   Empty, Q-CMB-11 can never be corroborated.
